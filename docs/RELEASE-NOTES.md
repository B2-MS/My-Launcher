# My Launcher — Release Notes

---

## v0.1.0 — Alpha (February 13, 2026)

**Initial alpha build.**

### Features
- Customizable home screen with app icon grid
- Searchable app drawer
- Gesture navigation for quick actions
- Android widget support (add and resize)
- Folder support (group apps by dragging)
- Material You dynamic theming
- Icon pack support
- Universal search (apps, contacts, web)
